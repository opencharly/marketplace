## Summary

The validator's PASS on #544 carried three non-blocking observations. Two of them are real
defects in that change's own text, and they are fixed here; the third is answered with
evidence. This is a FOLLOW-UP PR because #544 was already merged (squashed) when its verdict
landed: nothing is rewritten there — its commit, its body and its history stand — and this
PR carries only the two text fixes.

- `scripts/consumer-currency.sh` — the header comment named the PIN CONTRACT's state list
  (`cur`, `behind`, `blocked-by`, `not-on-the-served-line`) instead of the states the report
  emits. The report never emits `blocked-by`: that state names the SOURCE an edge pin waits
  on, while a consumer's recorded pin is read as a plain submodule gitlink and judged
  against this repo's merged main. And the report can always emit `undecidable` and
  `unreadable` — the two cases it refuses to guess — which the header did not mention at
  all. The header now names the three contract states the report can be in, says why
  `blocked-by` is not one of them, and names the two states that are the report's own.
- `README.md` — the `## Consumers` table's second column header was "Recorded pin" for a
  column that holds the PATH at which the consumer records the pin. The header read as a sha
  and the value was not one; it is "Pin path" now.
- `scripts/consumer_currency_test.sh` — the fixture's table carries the same header, so the
  fixture still mirrors the real table.
