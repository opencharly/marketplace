## How tested

The marketplace's own gate is the `deploy.yml` **drift gate**: the committed corpus must equal what regeneration from this repo's refs list produces (a clean-tree regeneration is a no-op). Reproduced locally with the binary the workflow pins:

```console
$ git clone --depth 1 --branch v2026.256.1316 https://github.com/opencharly/charly.git charly-pinned
$ (cd charly-pinned/charly && GOWORK=off go build -buildvcs=false \
    -ldflags "-X main.BuildCalVer=marketplace-ci" -o /tmp/charly-marketplace .)
$ /tmp/charly-marketplace version
marketplace-ci

$ # bump the pin
$ sed -i "s|layer-charly-check:v2026.260.1416|layer-charly-check:v2026.261.0617|" candy/charly-marketplace/charly.yml
$ /tmp/charly-marketplace marketplace generate --root "$PWD" --out "$PWD"
gen exit=0

$ # a SECOND generation must be a no-op (the drift gate)
$ /tmp/charly-marketplace marketplace generate --root "$PWD" --out "$PWD"
gen2 exit=0
$ git status --porcelain

 M candy/charly-marketplace/charly.yml
 M check/skills/jetkvm/SKILL.md
```
