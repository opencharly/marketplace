# 2026.271.1826 — feat(scripts): coord.sh — the generic verb-labelled coordination comment CLI

## Summary

Adds **`scripts/coord.sh`** — the ONE generic implementation of the `AGENTS.md`
agent-coordination comment grammar (the "Agent identity & comment coordination"
section, extends rule 9) — beside the already-merged watcher family. The watcher
family covers *waiting*; this covers *speaking*.

A coordination comment's first non-blank line must be ONE label from the closed set
`CLAIM · OWNING · HANDING OVER · TAKING OVER · BLOCKS · UNBLOCKS · STATUS · RESOLVED`,
and the comment must END with the canonical TWO-LINE footer in the order the
pr-validator accepts: `Agent:` FIRST, `Assisted-by:` LAST. Hand-writing that footer
is exactly where agents drift (wrong order, a missing session, an invented confidence
tier), so the grammar lives ONCE here (R3) and is consumed by humans, by agents, and
by the opencode `coord_comment` tool in a companion umbrella PR.

- `scripts/coord.sh` — `<VERB> <owner/repo#num> [--body|--body-file] [--agent …]
  [--session …] [--harness …] [--model …] [--confidence …] [--assign] [--dry-run]`.
  Fully generic: no org/repo/session/date baked in. Validates the verb against the
  closed set and the tier against the five canonical tiers; `--assign` performs the
  CLAIM (assigns the posting account). `set -euo pipefail`, `--help`, exit codes
  0/2/3/5.
- `scripts/coord_test.sh` — deterministic **stub `gh`+`jq`** coverage of every
  branch (help, bad verb, bad tier, missing identity/target, the canonical footer
  ORDER, verb normalisation, both target forms, `--assign`, `--body-file`,
  `--dry-run` makes no call) **plus an opt-in LIVE layer** (`COORD_LIVE_ITEM`) that
  posts and deletes a REAL comment — the real GitHub boundary, never a fake (R7).

Consumed by `opencharly/opencharly` `.opencode/plugins/coord.ts` (custom tools
`coord_comment`/`coord_watch`) via the marketplace pin.

## Rulebook compliance

- **R3 (no duplication):** the verb grammar + footer ORDER live ONCE here; the opencode
  tool and the CLAIM action delegate to this script rather than re-implementing it.
- **R7 (live or skip):** the GitHub boundary is covered by an opt-in LIVE post+delete
  layer that SKIPS visibly when `COORD_LIVE_ITEM` is unset — never a fake.
- **Generic by construction:** no org, repo, session, or date baked in.
- The marketplace is standalone; `scripts/` is hand-authored (not under the
  `DO-NOT-EDIT` generated corpus), so no regeneration is required.

## Review-round fixes

- **exit 3 was unreachable** — a real `miss()` path now exits 3 for a missing gh/jq
  (the header's documented contract is now true).
- The `--help` verb list now shows the canonical **spaced** labels (`HANDING OVER` /
  `TAKING OVER`); the test asserts the exact labels with `grep -qF`.
- `--` now ends option parsing; the dead `.git` suffix strip is removed.
- Coverage widened: unknown-option exit-2, the `--` arm, and the missing-gh exit-3 arm.
