# 2026.230.0833 — the carrier recipe stops naming a fixed /tmp path

Projection of `opencharly/charly#289`. One file — `internals/agents/pr-validator.md`.

The carrier-detection recipe published `git worktree add /tmp/carrier-<n>` and tore it down with
`worktree remove --force`. **The same source file mandates `mktemp`, not a fixed path, and pastes
the transcript of a fixed `/tmp` path destroying a peer's live worktree.** The recipe contradicted
the rule stated 5,000 lines above it, in the direction the rule exists to prevent.

It now uses `mktemp -d`, names its five inputs as shell variables, and carries no angle-bracket
placeholders — those parse as **shell redirections**, which is the defect this cutover's other leg
removed from two published guards.

**zero** remote branches and zero tags, so every figure was true and none was checkable from a fresh

## Round 3: the matcher is now named
