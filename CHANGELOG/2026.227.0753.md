# 2026.227.0753 — add the helm skill; publish the agentteams + helm dispatcher rows

The Factory north-star's unit 4 (docs catch-up) plugins leg
(`PROGRAM/factory-north-star.md`). Units 2 and 3 landed capability — the helm
words (`step:helm-release`, `verb:helm`, the `helm_charts:` emission) and
`verb:agentteams` — with no Skill Dispatcher row and, for helm, no skill at
all. A landed capability with no dispatcher row is unroutable from R0: every
future session touching it starts blind. This closes that gap.

- `kubernetes/skills/helm/SKILL.md` — NEW, generated from the `helm-skill:`
  entity added to `candy/charly-kubernetes/charly.yml`. Covers the
  `step:helm-release` install step (the `#HelmReleaseStep` field set, the
  KUBECONFIG precedence chain — an operator-set `KUBECONFIG` wins, else the k3s
  guest default `/etc/rancher/k3s/k3s.yaml` — and the `helm uninstall` ReverseOp
  the host records and replays), the four `verb:helm` methods
  (`release-exists`, `status`, `revision`, `values-hash`) with their
  method-exclusive modifiers, the `kubernetes:` substrate arm (`helm_charts:` →
  kustomize `helmCharts:` behind `--enable-helm`), and the two beds
  (`check-helm-vm`, `check-k8s-deploy`).

  The skill carries the authoring law the unit 2 cutover surfaced: a bed's own
  plan runs verify-only and `charly fleet add` lowers only CANDY plans' `run:`
  steps, so a mutating install must live in a candy's `run:` steps, never in the
  bed's plan — with the second-order trap that a `check:` step does not run
  during `fleet add`, so an install candy waits for node readiness itself.
  `candy/helm-chart` is the worked example.

- Dispatcher rows (generated into the superproject's `CLAUDE.md` + `AGENTS.md`
  between the `GENERATED SKILL DISPATCHER` markers, from `triggers:` on the
  skill entities — the table is generated, never hand-edited):
  `/charly-kubernetes:helm`, `/charly-agentteams:agentteams-cli` (the
  `charly agentteams` CLI + the `verb:agentteams` methods), and
  `/charly-agentteams:agentteams` (the box and its two beds). The agentteams
  family has shipped since its Unit 7 landing with zero dispatcher rows.

- `README.md` — the `charly-kubernetes` bucket row named only the `kube:` verb;
  it now names the helm words too.
