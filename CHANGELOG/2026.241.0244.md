# 2026.241.0244 — fix: drop candy/charly-marketplace's unresolvable charly repo-root entry

## Summary

`candy/charly-marketplace/charly.yml` is the **authoritative refs list** — `deploy.yml` copies it
over the charly checkout's copy before generating. Its first entry named the charly **repo root**:

```yaml
- '@github.com/opencharly/charly:v2026.240.2345'
```

A repo root is not a candy node, so that entry never resolved to anything.

**The diff removes it** and leaves a comment in its place. It is not repointed at charly's
candies, because it was never needed here: `marketplace generate --root <charly>` reads charly's
own candy dirs from disk, so charly's `skill:`/`hook:` entities reach the corpus through `--root`
and never through this list.

## Two commits, and why the first is superseded

1. **`7e1a059`** replaced the entry with nine `charly/candy/<name>` subpath refs.
2. **`772e982`** removes it outright. **This is the shipped state.**

The correction came from landing the same fix in charly, where
`TestCandyCutoverSweep_NoCharlyCandyRefs` rejected the subpath form as the OLD pre-cutover shape.
That gate matters *here* specifically because `deploy.yml` copies this file into the charly
checkout before generating — the nine refs would have been carried straight back into charly's
tree, past the test that exists to keep them out. Kept as two commits rather than a force-push
(R6).

## How tested

**1. Consumer-side — what the entry actually costs.** The defect is invisible in this repo and
fatal in consumers, so the proof it is a defect at all comes from a consumer. Measured on
`distro-cachyos`, which carries its own copy of this candy, both legs from committed trees:

```
$ git checkout main && charly box validate | grep -E 'unknown candy "github.com/opencharly/charly"'

   candy "charly-marketplace" candy: unknown candy "github.com/opencharly/charly"

$ charly box validate | grep -cE 'conflict|unknown candy|missing "socat"'
9
$ git checkout fix/…    # the same entry corrected
$ charly box validate | grep -cE 'conflict|unknown candy|missing "socat"'

$ charly box validate | grep -cE 'unknown candy "github.com/opencharly/charly"'
0
```

**Reconciling the remaining 7** — they are pre-existing and unrelated to this entry, and are
unchanged by it:

```
1 remote candy name conflict: "plugin-mcp"    provided by both …/charly and …/plugin-mcp
1 remote candy name conflict: "plugin-mcp"    provided by both …/plugin-mcp and …/charly
1 remote candy name conflict: "plugin-record" provided by both …/charly and …/plugin-record

1 box "openclaw-full":    has port_relay candies but missing "socat" candy
1 box "openclaw-desktop": has port_relay candies but missing "socat" candy
```

I had hypothesised those were downstream of this partial charly load. **They are not** — measured
directly, and reported here rather than left implied. They are open members of the post-cutover
plugin-candy pin reconciliation batch and are not touched by this PR.

**2. This repo — the risk removal actually carries.** The only way removing an inert entry can go
wrong is by moving the generated corpus. It does not. At the charly tag `deploy.yml` pins
(`v2026.240.2345`), on the final committed tree with a clean worktree:

```
$ git status --porcelain          # empty — committed tree
$ cp candy/charly-marketplace/charly.yml <charly>/candy/charly-marketplace/charly.yml
$ charly marketplace drift --root <charly@v2026.240.2345> --out <marketplace>
marketplace drift: clean (405 artifact(s) on disk match their sources; regeneration is a no-op)
drift exit=0

$ charly marketplace generate --root <charly@v2026.240.2345> --out <marketplace>
$ git status --porcelain
 M candy/charly-marketplace/charly.yml
```

Three-way, all byte-identical — which is what justifies removal over repointing, since the entry
demonstrably carried nothing:

| refs list | generate | corpus |
|---|---|---|
| broken repo-root entry | exit 0, no diagnostic | 405 artifacts, drift clean |
| nine `charly/candy/<name>` refs | exit 0 | 405 artifacts, drift clean |
| **entry removed (shipped)** | exit 0 | 405 artifacts, drift clean |
