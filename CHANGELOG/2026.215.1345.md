# 2026.215.1345 — `/charly-internals:skills`: the replacement claim carries the removal's burden of proof

Adds a rule the docs-site cutover paid for four times.

## What the rule says

Correcting a false doc/skill/comment produces **two** claims — the deletion and the successor —
and both need evidence. The failure mode is applying rigor to the deletion and a plausible guess
to what replaces it: the false claim is gone, a new one ships in its place, and the sweep that
would have caught it has already run.

## Why it earned a section rather than a sentence

Four replacements written during one cutover were themselves false, in four different repos, each
correcting the same stale `directory:` claim:

- "inline entries have no source directory of their own" — `ScanInlineCandy` is passed `rootDir`,
  and an inline candy's `SourceDir` always equals its declaring file's directory.
- "the branch fires for a remote or submodule-vendored candy" — `CandyCopySource` early-returns on
  `GetRemote()` as its first statement, so a remote candy never reaches that branch.
- "the 11 frontmatter references are published as plain subtitle text" — `firstLine` truncates the
  description to its first sentence; all 11 sit past the cut and are published nowhere.
- "3665 references … every reference is rewritten" — 3654 are rewritten; the count was taken
  whole-file and described as body-scope.

Every one shares a root cause: **measuring or reasoning at one scope, then describing another.**
Each was caught by a reviewer running the thing being described rather than reading the
description — which is the practical reason the rule is worth stating rather than assumed.

The section adds four rules: trace the successor before writing it (read the early returns above a
branch, read the emitter rather than the producer); state a partial enumeration as partial;
re-derive figures at the scope the sentence names, using the code's own matching rules where one
exists; and treat a correction as a new claim subject to the same gate as the original edit.
