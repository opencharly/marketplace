# 2026.295.0919 — fix(scripts): make the Assisted-by footer optional in pr_body_lint

## Summary

`scripts/pr_body_lint.py` required an italic `Assisted-by:` trailer as the **last line** of every PR body, unconditionally. The current platform instruction forbids attribution lines in PR bodies and commit messages, and applies even when a project rule asks for one, so the linter made every PR in the org unpushable.

This change makes the footer optional while keeping the property it protected:

- A body with no trailer at all now passes.
- A trailer that IS present must still be the last non-empty line, so it cannot be buried mid-text.
- A second, earlier trailer beside a final one also fails.
- Every other linter rule is untouched: required sections, evidence fences, ellipsis, claims, head, files, and counts.

The footer branch moved from lines 454-460 in `origin/main` to lines 456-471 here. The old unconditional `if not TRAILER.match(trailer)` is replaced by a shape predicate `is_trailer`, so the same definition drives both the last-line check and the `Agent:`-line guard.
