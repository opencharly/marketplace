# 2026.275.0303 — feat(scripts): pr_body_lint.py — fail-closed PR-body lint before the push

## Summary

Adds `scripts/pr_body_lint.py`: a deterministic, fail-closed lint of a PR body, run **before** the push. AGENTS.md calls a body-only validator BLOCK an "ORCHESTRATOR VALIDATION FAILURE". Until now the pre-validator self-audit existed only as prose, so nothing caught those failures mechanically.

It checks six things:

| Check | Fails when |
|---|---|
| sections | one of `## Summary`, `## How tested`, `## Rulebook compliance`, `## Change classification` is missing |
| footer | the last line is not the italic `Assisted-by` trailer, or an `Agent:` line does not directly precede it. The trailer grammar is **imported** from `squash_body.py`, the one definition. |
| rules | `## Rulebook compliance` does not answer every id in `--rules` (default R0–R10), or answers one with a bare `N/A` (fewer than two words of reason) |
| claims | an asserted check (a sweep result "only occurrence", a check reported as done "… were checked", an equivalence "match(es) `…`") has neither a later fenced `$ ` command block in its section nor an above/below pointer |
| head | a pasted `Head `<sha>`` differs from the commit being pushed (`--head` or `--repo`) |
| ellipsis | a fenced block contains `…`, because pasted output must be verbatim |

**The claim patterns are deliberately narrow.** They are the shapes the validator actually BLOCKed. A generic "every"/"none" in prose is not a check claim, and a noisy lint would teach authors to ignore it; my first draft flagged legitimate prose in every body and was narrowed to the measured shapes before this commit. The lint cannot judge whether evidence is *sufficient*; that stays the validator's job.

`scripts/pr_body_lint_test.py` pins it, with fixtures under `scripts/testdata/pr_body_lint/`:
- the **real** first-push bodies of two PRs the validator BLOCKed on the body alone, recovered from GitHub's `userContentEdits` history: opencharly/distro-fedora#79 and opencharly/docs#142;
- a body the validator PASSed: opencharly/marketplace#405.

Relates to #404. Two parts of #404's scope remain:
- **Wiring the lint into the pre-push gate.** That file is umbrella harness config, which opencharly/opencharly#332 is consolidating right now, so it lands after #332 to avoid a conflicting edit.
- **The self-audit "class 6 / step 3b"** prose in the `layer-charly-internals` skill source.
