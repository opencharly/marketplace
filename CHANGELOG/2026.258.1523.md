## R2 — the defects this refresh surfaced, fixed in THIS tree (not parked)

The prior reviewer round found the generated body internally inconsistent. The defects live in
`.github/workflows/refresh.yml`, so they would recur on every future run. Fixed here, in the
same diff as the refresh they correct:

1. **Collapsed untracked-dir count.** The generator used plain `git status --porcelain`, which
   collapses a new untracked directory to one `?? dir/` line, so an added `SKILL.md` was
   neither named nor counted. Now uses `-uall` (proven above), with the zero-match case
   normalised without the `|| echo 0` double-print.
2. **False "same skills" claim.** The breaking-change line asserted "none — the same skills at
   newer tags", false whenever a pin adds/removes a generated skill entity. Now derives the
   real added/removed/modified breakdown from the status codes.
3. **Declined attribution footer.** The Authorship section declined the AGENTS.md rule-6 footer
   and carried reviewer-directed argumentation. Replaced with a plain provenance statement plus
   the mandated footer.
4. **Stale refs-list comment** (found this round): the comment above the crabbox pins still
   advertised a check-verb skill entity this same refresh deletes. Swept in the refs-list hunk.
