# 2026.295.0934 — fix(scripts): require the Assisted-by trailer when the body carries an Agent: line

## Summary

`scripts/pr_body_lint.py` made the italic `Assisted-by:` trailer optional in #531. That is right for a human author, but it also let an agent-authored body pass with no trailer. This change conditions the optionality on the mechanical marker: a body carrying an `Agent:` line must end with the italic trailer; a body with no `Agent:` line keeps the optional behavior exactly as #531 landed it.

The agent-marker predicate accepts the plain and emphasis-wrapped forms (`Agent:`, `*Agent:*`, `**Agent:**`) and matches only at the start of a line. The footer branch reuses its existing `is_trailer` shape predicate and its `Agent:`-precedes-trailer guard; the guard now reads the same marker predicate. No other linter rule changes.

Files carrying the change: `scripts/pr_body_lint.py` and `scripts/pr_body_lint_test.py`.
