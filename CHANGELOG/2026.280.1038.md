# 2026.280.1038 — fix(watch): raise the poll interval default and POLL_FLOOR to 300s (#425)

## Summary

Operator directive (2026-10-07): set the watcher family's poll cadence to 5 minutes and upstream it.
Scoped by explicit choice to **all three watchers AND the poll floor**.

- `scripts/_watch_common.sh` - `POLL_FLOOR=60` -> `300`, plus the rationale block and the
  parse-time refusal message.
- `scripts/gh_watch.sh` - `INTERVAL="${INTERVAL:-60}"` -> `300`, plus the header usage, the
  "ONE POLL PER FIVE MINUTES" statement and the budget paragraph.
- `scripts/pr_watch_many.sh` - `INTERVAL=60` -> `300`, plus the header and comment.
- `scripts/pr_state_watch.sh` - `PR_STATE_INTERVAL:-60` -> `300`, plus the header, usage text and
  comment.
- `scripts/watch_family_test.sh` - the assertions that PIN those values move with them
  (`POLL_FLOOR is 300`, the three default assertions, the floor-accept case, the sub-floor
  refusal label).

**`STALL_MIN` is deliberately untouched.** It is the stall window in MINUTES
(`STALL_MIN="${STALL_MIN:-60}"`, `--stallmin`), a different knob; a blind 60 -> 300 sweep would
have corrupted it. The diff confirms no `STALL_MIN` line changed.

Why: #373 established the 60s floor after the shared API budget was exhausted by fast/stacked
polls. With the family's batched poll the billable cost is **one request per poll for the whole item
list**, so the saving is a flat factor of five: a watch drops from about **60 requests/hr at the old
60s default to about 12 requests/hr at 300s, regardless of how many items it watches**. The cost is
up to 5 minutes of latency on a merge/unblock signal, accepted explicitly by the operator.

(Correction, B5: an earlier revision of this body said "1080 to 216 REST calls/hr". Those figures
came from the per-item `snapshot()` model - 6 calls per item per poll - which the same script
documents as superseded by the batched poll. The body now states the model the committed comment
states.)
`ALLOW_FAST_POLL=1` remains the test-only escape hatch, unchanged.

Closes #425.
