# 2026.256.1902 — ci: bump the pinned charly to a schema-capable tag

## Summary

The `deploy.yml` and `refresh.yml` workflows cloned charly **`v2026.241.1243`**, whose binary supports config schema **max `2026.240.1943`** — older than this repo's own `charly.yml` (`version: 2026.249.2125`). So `charly marketplace generate` failed at project load:

```
charly: error: command "marketplace": load project: loading charly.yml: … config schema 2026.249.2125 is newer than this charly supports (max 2026.240.1943). Update charly …
```

The drift gate never ran, and the committed corpus could not refresh. Bump both pins to **`v2026.256.1316`**.
