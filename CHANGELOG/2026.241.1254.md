### Both halves must move together

This is one atomic change for a correctness reason, not convenience:

- **The refs alone**, against a charly that still carries the candies, would put the same 8 candies
  in the closure **twice**.
- **The pin alone** would drop **62 skills** out of the corpus entirely.

### What this actually removes

`charly/candy/` was the corpus's **second input path**. Those 62 skills reached the corpus only
because CI clones charly at a hand-written tag — which is exactly how a stale pin can freeze skill
content while every gate stays green, the failure mode that motivated this cutover. They now resolve
from the refs list like every other standalone repo.

### The five fixtures are deliberately not listed

`check-local-layer`, `check-stack-layer` and the three `*-consumer` candies were also extracted, but
own **zero `skill:`/`hook:` entities**. This list is defined as the repos that own such entities, so
adding them would be noise. They were extracted so `charly/candy/` could be emptied, not because the
corpus needs them.
