# 2026.206.0000 — Parseable squash attribution contract

The Git workflow now constructs every AI-assisted squash body through one
parser-backed helper. The exact bytes sent to GitHub contain a blank line
before the standalone trailer:

`Assisted-by: <Harness> <Provider Full Model Name> (<confidence>)`

The helper rejects same-line and single-newline placements, noncanonical
identity or confidence placeholders, duplicate attribution text, and any body
whose `git interpret-trailers --parse` output is not exactly the expected
trailer. The fresh PR validator verifies those same bytes before merge and the
fetched merge object before tagging or reporting completion.

This executable harness-policy change has no runtime candybox impact. Its
parser self-test is part of the portable skill validator.
