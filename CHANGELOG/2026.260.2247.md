# 2026.260.2247 — fix(refresh): the generated body proves what ran, states the footer field

## Summary of changes

The nightly `refresh.yml` workflow emits a fixed PR body for every `chore: refresh the refs
list` PR. That body could not pass A1 (it blocked marketplace#306). This PR fixes the emitter:

1. **Attribution footer.** The body ended with a self-authored `## Authorship` section arguing
   that `Assisted-by:` does not apply. It now emits the MODEL-FREE form
   `*Assisted-by: GitHub Actions ubuntu-latest (fully tested and validated)*`, defined by the
   merged A1 amendment `opencharly/action-review#6` (maintainer sign-off).
2. **Complete, well-formed rule-compliance section.** The emitted body carried no
   `## Harness rulebook compliance` block at all (and previously stopped at R9); it now emits
   R0–R10 plus RDD/ADE/SDD and hard-cutover, with closed code spans.
3. **Real evidence instead of assertions.** It captures `charly marketplace generate`'s full
   output (`tee /tmp/generate.log`) and pastes it; pastes the refs-resolution lines; splices the
   actual `deploy.yml` drift-gate step (captured into a variable that **fails loud** with an
   explicit ERROR marker when the anchors move, since a bare `sed` range emits nothing on drift);
   and derives the R1 zero-warning line from the resolver's own summary line
   (`grep -E 'refresh-refs: [0-9]+ pin\(s\) advanced, [0-9]+ unresolved' … | tail -1`), with an
   explicit ERROR marker when it is absent. It also emits the emitted-body counts (`BUMPED`,
   `FILES`, `ADDED`, `REMOVED`, `MODIFIED`, `SKILLS`) derived from the logs/`git status`.
4. **Failure semantics (`set -o pipefail`).** The run step now uses `set -o pipefail` so a
   failing generator fails the step instead of being masked by `tee`'s exit status — a
   deliberate behavior change in this diff (a generator failure that previously left the step
   green now fails it).

**Closes / relates to:** relates to the closed marketplace#306.

**Breaking change + rollback:** behavior change is limited to (a) the emitted body text and
(b) the run step's failure semantics (`set -o pipefail`, #4 above). Revert restores both.
