## The fixture did not run

`#175` added a fixture to the evidence block, introduced as "the fixture, so you can rerun this", to satisfy the rule that everything runnable on the page is executed before publication. It opened `git init -q repo`. Git's out-of-the-box default branch is still `master`, so line 4's `git switch -q main` died for any reader without `init.defaultBranch` configured:

```
$ git init -q repo && cd repo && git symbolic-ref --short HEAD
master
$ git switch -q main
fatal: invalid reference: main            # exit 128, on git 2.55.0 with a clean HOME
```

It is now `git init -q -b main repo`, verified verbatim against a git with no `init.defaultBranch` anywhere: exit 0, branches `main side-a side-b`, and `merge-tree --write-tree side-a side-b` exiting 1 as the block claims.

The failure is worth naming precisely, because the page's own rule did not prevent it: the fixture WAS executed, but in a shell whose git had `init.defaultBranch=main` — the author's environment rather than the reader's. Executing a command proves it runs where you ran it. The published form still has to be run as published.
